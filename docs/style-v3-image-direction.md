# Style V3 image direction

## Source policy

- Xiaohongshu and Pinterest are research references for composition, styling relationships, and current visual language only.
- Do not embed, download, trace, or remove marks from creator posts.
- Website assets must be either generated specifically for this product or sourced with explicit commercial-use rights.
- The 40-image evaluation set remains isolated from product UI and is only used for internal model evaluation.

## Shared campaign language

- Full-body subject where available, visible garment relationships, and enough contrast to read color, footwear, texture, and layering. Backgrounds may range from studio color to real street context.
- Consistent camera height and subject scale so users compare clothing rather than photography quality.
- No logos, influencer UI, platform marks, celebrity likenesses, or fixed internet-style labels.
- Each theme has three related but distinct concentrations: daily, expressive, experimental.
- The first four samples must cross four different visual families; no user should be anchored by several monochrome looks before seeing color, print, texture, and sport.

## Diversity balance

- Low-saturation neutrals remain one valid direction, not the default direction.
- The sampling pool must also include color blocking, graphic print, pastel color, crochet/handmade texture, sport-romance contrast, street utility, and visible accessories.
- Diversity comes from styling relationships and material language as well as hue; simply recoloring the same silhouette does not count.

## Theme-to-image contract

| Theme | Daily | Expressive | Experimental |
| --- | --- | --- | --- |
| Quiet Structure | crisp shirt, straight trousers, light tailored coat | relaxed sculptural tailoring | architectural monochrome layers |
| Soft Utility | soft overshirt and fluid cargo trousers | controlled technical layering | asymmetric shell and generous utility volume |
| Modern Romance | fluid blouse and long clean skirt | translucent-over-opaque layering | sculptural drape with restrained sheer panels |
| Relaxed Tailoring | relaxed blazer and straight trousers | oversized jacket and fluid trousers | deconstructed asymmetric tailoring |
| Sculptural Mono | tonal column silhouette | amplified monochrome volume | strong wearable geometric construction |
| Retro Color | one muted retro accent | two-color modern proportion play | high-energy color with one controlled focal point |
| Crafted Layering | one visible textured layer | mixed tactile surfaces and quiet asymmetry | rich crafted layers with one handmade focal detail |
| Polished Sport | clean knit and streamlined trainer | technical-soft contrast | refined sport construction with sculptural proportion |

## Current asset status

- The internal 40-image evaluation set is no longer referenced by product UI code.
- Original generation remains the preferred production direction once the built-in generation service is available again.
